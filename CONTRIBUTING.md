# Contributing

Thanks for helping improve the NeuroSK techniсal reference dataset.

## Compatibility corrections 

For a compatibility correction, include:

- affected method;
- NeuroSK version;
- Windows version/build;
- relevant vendor/driver version;
- exact observed behavior;
- reproduction steps;
- evidence where possible.

Do not submit unverified claims about game or anti-cheat compatibility as facts.

## Benchmark contributions

Benchmark pull requests should include:

1. a completed row in the appropriate data file;
2. the environment details required by `docs/reproducibility.md`;
3. raw measurements or logs where practical;
4. a short methodology note if the standard methodology was changed.

## Privacy

Do not upload:

- NeuroSK license keys;
- private repository source code;
- model weights not intended for public distribution;
- access tokens or secrets;
- personal identifiers from logs;
- payment or account data.
