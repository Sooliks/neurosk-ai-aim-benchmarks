# Documentation and dataset reuse

Unless a file states otherwise, the documentation and datasets in `docs/`, `benchmarks/`, and `data/` may be reused with attribution to the **NeuroSK Project** and a link to the original repository or canonical NeuroSK reference page.

Recommended attribution:

> Source: NeuroSK Research & Benchmarks, https://neurosk.pro/en

For formal publication or redistribution, use the citation metadata in `CITATION.cff`. The intent of this repository is to make technical reference material reusable and citable while preserving clear provenance.
